HOW THE SIMULATION WORKS

Working principle

The complete irrigation process, explained step by step.

Website simulation · No physical devices
  1. 01
    Generate simulated readings

    The website starts with sample soil moisture and weather values. You can change soil moisture with the sensor slider or simulate rain with the weather control.

  2. 02
    Check the moisture threshold

    JavaScript checks the simulated soil value against the start threshold saved in Irrigation Control.

  3. 03
    Decide whether watering can start

    Automatic Mode requests irrigation only when soil is below the threshold, water is available, and an enabled rain delay is not active. Manual Mode follows the user’s pump buttons.

  4. 04
    Run the virtual pump

    Every two seconds, a running pump increases simulated soil moisture and water consumption while reducing the simulated tank level.

  5. 05
    Stop safely

    Automatic watering stops at the configured target. In either mode, the pump stops if the tank becomes empty. An active rain delay prevents automatic watering from starting.

  6. 06
    Update the dashboard

    Readings, Chart.js graphs, notifications, and the saved activity history reflect the latest simulation state. The process repeats on the next timer check.

PROJECT OVERVIEW

About Project

Project information for college demonstration and evaluation.

DIPLOMA PROJECT DEMO
✳
PROJECT TITLE

Smart Irrigation System Website Simulation

This is a website-based simulation of an IoT smart irrigation system. All sensor readings, weather conditions, tank values, and pump actions are simulated in the browser. No physical sensors, pumps, IoT hardware, or real-time weather API are connected.

▤

Abstract

The project demonstrates how a smart irrigation system can use soil moisture and weather information to decide when watering is needed. An interactive website simulates sensor readings, automatic and manual pump modes, tank safety, and rain delay. Users can observe changing readings through dashboard cards, charts, and an activity log. The simulation is designed as a clear learning and presentation aid; it does not control real irrigation equipment or report actual field measurements.

❝

Problem statement

Manual irrigation can waste water when crops receive more than they need, while infrequent checks can leave soil too dry. This project presents a simple way to learn how moisture-based decisions can help manage irrigation.

◎

Objectives

  • Demonstrate moisture-based irrigation rules.
  • Show simulated sensor and weather readings.
  • Track water use, pump cycles, and activity.
  • Provide an interactive learning dashboard.
↗

Proposed solution

A responsive browser dashboard simulates soil and weather sensors, a water tank, and a virtual pump. Users can adjust readings, choose automatic or manual mode, and observe resulting events and trends.

▦

Main features

  • Live simulated readings and interactive sliders.
  • Automatic rules and manual pump controls.
  • Rain simulation, delay, and tank safety.
  • Charts, notifications, and saved activity.
⌘

Technology stack

HTML5CSS3Vanilla JavaScriptChart.jsBrowser LocalStorage

Chart.js is loaded from its CDN. No framework, server, or database is used.

✧

Advantages

  • Simple to run and explain in a presentation.
  • Demonstrates automatic and manual control.
  • Shows simulated water trends and event history.
  • Responsive and does not need special equipment.
△

Limitations

  • Values are simulated, not measured in a real field.
  • No physical pump, sensors, or IoT hardware.
  • No real-time weather API or field testing.
  • Saved data stays in this browser on this device.
➜

Future scope

A future hardware project could connect calibrated soil sensors, a microcontroller, a safely controlled real pump, and a weather data service. Multi-field management and secure remote reporting could also be explored.
